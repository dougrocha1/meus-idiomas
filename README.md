# 🌎 Meus Idiomas

**Aprenda, pratique e organize seus idiomas em um só lugar!**

Meus Idiomas é um aplicativo de flashcards desenvolvido para facilitar o aprendizado e a organização de vocabulário em diferentes idiomas.

Com uma interface moderna, intuitiva e inspirada no estilo retrô, o aplicativo oferece uma maneira simples e prática de estudar, revisar e memorizar palavras e expressões.

## ✨ Funcionalidades

- 🗂️ **Flashcards:** organize e pratique seu vocabulário por meio de cartões interativos.
- 🌍 **Multilíngue:** utilize o aplicativo para organizar estudos de diferentes idiomas.
- 🔄 **Revisão:** visualize perguntas e respostas para reforçar a memorização.
- ⚙️ **Configurações de idioma:** interface adaptável ao idioma do sistema, com opção de alteração manual.
- 💾 **Armazenamento local:** mantenha suas informações disponíveis no próprio dispositivo.
- 📱 **Interface responsiva:** experiência adaptada para diferentes tamanhos de tela.
- 🎨 **Design retrô:** visual inspirado na estética dos videogames clássicos.

## 🛠️ Tecnologias

O projeto foi desenvolvido utilizando tecnologias fundamentais da Web:

- HTML5
- CSS3
- JavaScript

Sem a necessidade de frameworks pesados, mantendo uma estrutura leve e acessível diretamente pelo navegador.

## 🎯 Objetivo

O objetivo do Meus Idiomas é tornar o aprendizado de novos idiomas mais organizado, acessível e agradável.

Acreditamos que aprender uma língua é um processo contínuo, construído com pequenas práticas diárias.

## 🚀 Acesso

O aplicativo foi desenvolvido para funcionar diretamente no navegador, sem necessidade de instalação de programas adicionais.
